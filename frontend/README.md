# Enube Frontend

Frontend desenvolvido para consumir as rotas da API do projeto Enube Backend. O projeto foi construído utilizando **ViteJS**, **React** e **Material UI**.

## Como Executar

1. Instale as dependências:

   ```
   npm install
   ```

2. Crie um arquivo `.env` na raiz do projeto com a seguinte variável de ambiente:

   ```
   VITE_API_URL=http://localhost:8080/api/v1
   ```

3. Inicie o servidor de desenvolvimento:

   ```
   npm run dev
   ```

O frontend ficará disponível em `http://localhost:5173`.
